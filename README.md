# nextra-ai

استوديو أوامر ذكاء اصطناعي مصغّر: صفحة رئيسية بأداة توليد مباشرة، و14 أداة متخصصة (نصوص، صور، أدوات مضبوطة على ChatGPT/Claude)، بواجهة ثنائية اللغة (عربي/إنجليزي، RTL/LTR كامل).

مبني بـ Next.js 15 + Tailwind CSS. محركان مختلفان لمهمتين مختلفتين:
- **Groq** (يحتاج مفتاحك المجاني) لكل أدوات النصوص وتحليل الصور — سريع جدًا وله باقة مجانية سخية يوميًا
- **Pollinations.ai** (بدون أي مفتاح) لأداة توليد الصور الفعلية فقط — المتصفح يطلب الصورة مباشرة، السيرفر ما يتدخل إطلاقًا

## 1) التشغيل محليًا

```bash
npm install
cp .env.example .env.local
# افتح .env.local وضع مفتاحك:
# GROQ_API_KEY=gsk_...
npm run dev
```

افتح http://localhost:3000

### الحصول على مفتاح Groq مجانًا
1. ادخل https://console.groq.com/keys
2. سجّل دخول (بدون بطاقة بنكية)
3. اضغط **Create API Key** وانسخ المفتاح (يبدأ بـ `gsk_`)

بدون هذا المفتاح، الموقع يفتح ويظهر بشكل كامل، لكن أدوات النصوص تُظهر رسالة واضحة تطلب إضافة المفتاح بدل التوليد الفعلي. أداة توليد الصور (`/tools/image-generate`) تشتغل بدون هذا المفتاح أصلاً، لأنها لا تمر بالسيرفر.

### إذا ظهر خطأ بعد النشر
كل خطأ يظهر على الشاشة نفسها بين قوسين مربعين، مثل `[RATE_LIMIT]` أو `[TIMEOUT]` أو `[HTTP_401]`:
- **`[MISSING_API_KEY]`**: لم تُضِف `GROQ_API_KEY` في Vercel بعد — أضفه من Settings → Environment Variables وأعد النشر
- **`[HTTP_401]`**: المفتاح خطأ أو منتهي — تأكد من نسخه كامل بدون مسافات من console.groq.com/keys
- **`[RATE_LIMIT]` أو `[HTTP_429]`**: تجاوزت الحد اليومي المجاني لـ Groq (سخي، لكن له سقف) — ينتظر حتى إعادة التعيين أو يترقّى الحساب
- **`[TIMEOUT]`**: الشبكة كانت بطيئة تلك اللحظة، جرّب مرة ثانية

### لماذا Groq بدل Pollinations للنصوص؟
جرّبنا Pollinations للنصوص وواجهنا فشلًا متكررًا من خوادم Vercel تحديدًا (بما في ذلك خطأ 402 لاحقًا) — على الأغلب بسبب مشاركة Vercel لعناوين IP بين آلاف المشاريع، وتضييق Pollinations لسياسة الوصول المجهول لاحقًا. Groq مستقر أكثر بكثير مع مفتاح شخصي حقيقي، وسريع جدًا. Pollinations بقي فقط لتوليد الصور الفعلي، حيث المتصفح — لا Vercel — هو من يطلب الصورة مباشرة، فمشكلة الـ IP المشترك لا تنطبق هناك.

### ماذا عن Grok (xAI)؟
xAI أوقفت الباقة المجانية لواجهة Grok البرمجية منذ مايو 2025 — الاستخدام عبر API مدفوع بالكامل الآن. لهذا لم يُستخدم هنا.

### ولماذا لا يوجد توليد فيديو؟
بصراحة: لا توجد حاليًا (أغسطس 2026) أي خدمة توليد فيديو احترافية مجانية بالكامل وبدون تسجيل وبلا حدود قابلة للتضمين في موقع عام. كل الخيارات "المجانية" (Kling، Luma، Veo عبر AI Studio...) تتطلب حساب، ومحدودة برصيد يومي خاص بصاحب الحساب — أي أن كل زوار الموقع سيتشاركون نفس الرصيد المحدود ويستنفدونه بسرعة، وغالبًا مع علامة مائية. الخيار الصادق حاليًا: إبقاء أداة الفيديو خارج الموقع الآن.

## 3) النشر على Vercel

**الطريقة الأسهل (بدون سطر أوامر):**
1. ادخل https://vercel.com وسجّل دخول (يفضّل بحساب GitHub نفسه)
2. اضغط **Add New → Project**
3. اختر مستودع `nextra-ai` الذي رفعته على GitHub
4. في خطوة **Environment Variables** أضف:
   - `GROQ_API_KEY` = مفتاحك (يبدأ بـ `gsk_`)
5. اضغط **Deploy**

بعد دقيقة أو دقيقتين يصير الموقع منشورًا على رابط مثل `nextra-ai.vercel.app`، وتقدر تربط دومين `nextra.ai` الخاص بك من **Settings → Domains**.

**أو عبر سطر الأوامر:**
```bash
npm i -g vercel
vercel login
vercel --prod
```
سيسألك عن متغيرات البيئة تفاعليًا أو تقدر تضيفها لاحقًا من لوحة تحكم Vercel.

## 4) بنية المشروع

```
app/
  layout.js            التخطيط العام + الخطوط (Cairo للعناوين، Tajawal للنصوص)
  page.js               الصفحة الرئيسية (Hero + شبكة الأدوات)
  tools/[slug]/page.js   صفحة أداة ديناميكية (نص / رؤية / توليد صورة)
  api/text/route.js      مسار خادمي لأدوات النصوص (يستدعي Groq)
  api/vision/route.js    مسار خادمي لأدوات تحليل الصور (يستدعي Groq Vision)
components/               عناصر الواجهة (Header, Footer, أدوات النص/الرؤية/توليد الصور...)
lib/
  tools.js               كتالوج الأدوات الأربع عشرة (العناوين + الأوامر الموجهة للنموذج)
  i18n.js                نصوص الواجهة بالعربي والإنجليزي
  groq.js                 دوال استدعاء Groq (نص + رؤية)
```

لإضافة أداة جديدة: أضف عنصرًا جديدًا في `lib/tools.js` فقط — لا حاجة لصفحة أو مسار جديد.

## 5) ملاحظات

- الشعار المستخدم في الترويسة هو رمز مبسّط (SVG) مستوحى من شعارك؛ ملف الشعار الأصلي موجود في public/logo.jpg ويمكن استخدامه في أي مكان تريده.
- تصميم الموقع أصلي بالكامل (ألوان، خطوط، تخطيط، نصوص) ولا يعيد إنتاج أي موقع تجاري آخر — وهذا مقصود.
- 13 أداة نصية/تحليل صور تعمل عبر Groq (يحتاج مفتاحك)، وأداة توليد الصور الفعلية (tools/image-generate) تعمل عبر Pollinations.ai مباشرة من المتصفح بدون أي مفتاح.
- لا يوجد في الموقع توليد فيديو حاليًا لأنه لا يوجد بديل مجاني حقيقي وبلا حدود يصلح لموقع عام — راجع القسم أعلاه لتفاصيل السبب.
- استضافة الموقع عبر Termux و Ngrok على الجوال ممكنة تقنيًا لكنها غير مناسبة لموقع احترافي دائم يخدم الجميع: الرابط يتغيّر، ويتوقف الموقع بمجرد إغلاق التطبيق أو انقطاع الجوال عن الإنترنت. Vercel (المستخدم في هذا المشروع) مجاني دائمًا لهذا الحجم من المواقع، ويبقى يعمل 24/7 بدون أي جهاز مفتوح.
